# Yandex Music - Stats

Плагин для PulseSync, собирающий статистику прослушанных треков Яндекс Музыки.
# Чтобы открыть статистику нажмите на кнопку сверху.
Плагин написан с помощью Deepseek, хотел реализовать отдельным окном как мини плеер, но дипсик обосрался и я забил.
Главное - плагин работает, статистику собирает. Если найдете баги или есть предложения по улучшению - тг @wermaxyy, или делайте сами ;)

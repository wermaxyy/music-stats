# Yandex Music — Stats

![Баннер](banner.jpg)

Плагин для PulseSync, который собирает статистику прослушанных треков в Яндекс Музыке и показывает её на отдельной вкладке «Статистика» в боковом меню.

## Возможности

- общее количество прослушанных треков;
- топ-15 исполнителей;
- топ-15 треков;
- экспорт статистики в JSON;
- очистка данных одной кнопкой.

## Установка

1. Скачай файл `music-stats.pext` из раздела [Releases](../../releases).
2. Дважды кликни по нему — плагин установится сам.
3. Если вкладка «Статистика» не появилась в боковом меню, перезапусти Яндекс Музыку.

**Требования:** PulseSync версии 5.0.0 и выше.

## Как пользоваться

Открой вкладку **«Статистика»** в боковом меню (под «Коллекцией»). Закрыть её можно кликом по любому другому пункту меню, клавишей `Esc` или переходом на другую страницу.

В нижней части страницы две кнопки:

- **Экспорт в JSON** — сохраняет всю статистику в файл `stats_ГГГГ-ММ-ДД.json`;
- **Очистить данные** — удаляет всю статистику (спросит подтверждение).

## Как считается статистика

- Трек засчитывается, когда он играл не менее **30 секунд**. Пропущенные треки и время на паузе не учитываются.
- Один и тот же трек, который играет подряд (повтор), считается один раз.
- Данные хранятся только на твоём компьютере, внутри Яндекс Музыки в PulseSync, и никуда не отправляются.
- Если очистить данные приложения или переустановить его, статистика пропадёт. Чтобы её сохранить, периодически делай экспорт в JSON.

## Известные ограничения

- После обновления Яндекс Музыки могут измениться элементы интерфейса, и плагину понадобится обновление.
- Подсчёт идёт по данным плеера, поэтому треки, которые играли до установки плагина, в статистику не попадут.
